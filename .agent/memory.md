## Learnings
- When adding Google Fonts, consider using `next/font/google` instead of `@import` in `globals.css` to prevent layout shifts.
- When creating new navigation links, ensure they are added to the translation files (`messages/en.json`, etc.) to maintain i18n support.
- Ensure the Navbar includes a mobile drawer or hamburger menu for mobile responsiveness instead of simply hiding links.
## Phase 1 Review Findings
- **Typography bug:** In `globals.css`, mapped CSS variables need to reference the custom property generated by `next/font/google`, i.e., `--font-sans: var(--font-sans);` and `--font-serif: var(--font-serif);`, rather than hardcoded string literal names, otherwise Next.js optimizations fail.
- **Image Check:** Verify Unsplash image URLs via `curl -I` before implementing them to ensure they return a 200 OK. The current hero image is broken.
